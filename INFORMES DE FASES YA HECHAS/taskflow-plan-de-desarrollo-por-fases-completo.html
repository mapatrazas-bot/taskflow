¿Qué es TaskFlow?

TaskFlow es una API REST para gestión de tareas personales/laborales. Permite crear, actualizar, consultar y eliminar tareas organizadas por categorías y prioridades, con autenticación JWT y documentación automática con Swagger/OpenAPI.

Requerimientos funcionales:

  • CRUD completo de tareas (título, descripción, estado, prioridad, fecha límite)
  • Categorías: PERSONAL, TRABAJO, ESTUDIO, OTRO
  • Estados: PENDIENTE, EN_PROGRESO, COMPLETADA, CANCELADA
  • Prioridades: BAJA, MEDIA, ALTA, URGENTE
  • Filtrado por estado, categoría y prioridad · Paginación y ordenamiento
  • Estadísticas básicas (total por estado, tareas vencidas)
  • Autenticación JWT · Roles USER / ADMIN
  • Documentación Swagger/OpenAPI · Desplegado en AWS · Orquestado con Kubernetes

Grupo 3 — REST API Completa
3
REST API + DTOs + Validación + Excepciones + Swagger
Todos los verbos HTTP · Status codes · Headers · CORS · DTOs · Swagger · Postman

REST completo

  • @RestController, @RequestMapping
  • GET — listar y obtener tarea por id
  • POST — crear tarea
  • PUT — reemplazar tarea completa
  • PATCH — actualizar solo estado
  • DELETE — eliminar tarea
  • @PathVariable y @RequestParam
  • @RequestBody — JSON input
  • ResponseEntity con status codes
  • Headers personalizados
  • CORS configurado

Calidad de API

  • DTOs de Request separados de Response
  • @Valid + Bean Validation completo
  • @NotBlank, @Size, @Future, @Min
  • @ControllerAdvice global
  • Estructura ApiError estándar
  • Query Parameters: filtros
  • Pagination: page, size, sort
  • Filtering: por estado/prioridad/categoría
  • Sorting: por fecha, prioridad
  • Swagger / OpenAPI 3.0
  • Postman Collection exportada
Entregable: CRUD completo con datos en memoria. DTOs separados, validaciones activas, manejo de errores global con ApiError, paginación/filtros/sorting, documentación en /swagger-ui.html. Postman collection lista.
